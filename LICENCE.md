## 🧩 About

**The Long Dark Companion** is a curated list of The Long Dark open-source tools:

- **Overlays** — on-screen helpers, layout notes, condition and temperature monitors, map overlay
- **Quality-of-Life Helpers** — inventory organizer, item catalog, crafting planner
- **Research Notes** — survival strategies, map routes, and configuration notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Condition Monitor — real-time display of health, hunger, thirst, fatigue, and cold
- Temperature Overlay — shows ambient temperature and wind chill
- Map Overlay — in-game map with player position and points of interest
- Item Tracker — log and highlight nearby resources

### Wallhack
- Inventory Sort — quick-sort items by category
- Crafting Planner — list required materials for recipes
- Weight Calculator — total carried weight and encumbrance alerts
- Item Catalog — browse all items with descriptions and spawn codes

### Aimbot
- Route Planner — plan travel routes with waypoints
- Wildlife Tracker — note animal spawn locations and behavior
- Weather Forecast — approximate weather patterns for planning
